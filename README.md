# alu-ml-private

Private ALU machine learning notebooks — formative assignments and Coursera exercises.

## The problem

You're working through ALU ML coursework and Coursera deep learning notebooks. You need a private repo for graded submissions and personal notes.

## What it does

Jupyter notebooks: ALU formative assignments (`formative1/`) and Coursera modules (NumPy basics, logistic regression neural network mindset).

**Keep this repo private** — contains academic work.

## Install

```bash
git clone git@github.com:irachrist1/alu-ml-private.git
jupyter notebook
```

## How it works

- **Notebook-per-assignment.** Each `.ipynb` is a self-contained ALU or Coursera submission.
- **Private by intent.** Not for public star/share — academic integrity and personal notes.
- **Companion to [alu-machine_learning](https://github.com/irachrist1/alu-machine_learning).** Public repo holds checker exercises; this holds private coursework.
